# ТЗ: Telegram-бот для структурирования задач (рабочее название — ТЗ-бот)

Финальная версия черновика — все открытые вопросы закрыты, документ готов для передачи в разработку.

## 1. Идея и цель

Подписочный Telegram-бот для людей, которым на работе присылают неструктурированные
задачи текстом в мессенджере (ТЗ, поручения, договорённости) — и которым неудобно
вручную переносить это в Notion, бумажку и т.п.

Пользователь пересылает боту сообщение(я) с задачей (или вводит текст сам), бот с
помощью ИИ превращает это в аккуратную структурированную карточку с полями и
кнопками управления, а исходное «грязное» сообщение через некоторое время
автоматически удаляется из чата, чтобы не засорять его.

Продукт IPAKOR, планируется к продаже знакомым и в целом по Узбекистану, не только
для личного использования.

## 2. Пользовательский флоу

### 2.1. Получение задачи
Два равнозначных способа создать задачу:
- **Форвард.** Пользователь пересылает боту сообщение(я) от коллеги. Форвард — однозначный сигнал, обрабатывается сразу, без дополнительных действий.
- **Ручной ввод.** Пользователь нажимает кнопку **«➕ Новая задача»** в меню — бот переходит в режим ожидания текста, следующее сообщение(я) — это и есть задача. Кнопка нужна, чтобы отличить «это новая задача» от случайного сообщения в чате с ботом. Для задач, введённых так, поле «От кого» по умолчанию — «Себе».

### 2.2. Несколько сообщений на одну задачу
- Альбомы фото — используется `media_group_id` от Telegram, склейка однозначна
- Несколько текстовых сообщений подряд — **пауза-таймер 3-5 секунд**: бот ждёт тишины после последнего сообщения, затем собирает всё вместе и отправляет на структуризацию. Без дополнительной кнопки от пользователя

### 2.3. Структурирование через ИИ
Текст (и изображение, если есть — см. раздел 8) отправляется в **Claude API (модель
Haiku)** с запросом разобрать его на три поля карточки (раздел 3) и вернуть текст
задачи на языке оригинала (см. раздел 7 — контент не переводится).

### 2.4. Отправка карточки и автоудаление исходника
Бот отправляет структурированную карточку (раздел 3). Исходное сообщение
пользователя (форвард или ручной текст) удаляется автоматически **через 2 минуты**
после отправки карточки — стандартная возможность Telegram Bot API: боты могут
удалять входящие сообщения в приватном чате с собой.

## 3. Карточка задачи — поля

| Поле | Содержимое |
|---|---|
| 👤 От кого | Имя/юзернейм отправителя исходного сообщения. Если у отправителя в Telegram включено «скрывать при пересылке» — бот не получит имя автоматически, пользователь вписывает вручную (просто текстом, без ссылки на чат). Для задач через «Новая задача» — по умолчанию «Себе» |
| 📅 Дедлайн | Срок, извлечённый ИИ из текста (в т.ч. относительные формулировки — «до пятницы», «завтра к обеду», с учётом текущей даты и часового пояса Ташкента). Если срока в тексте нет — **«не указано»** |
| 📝 Задача | Переформулированная, понятная суть задачи |

Если в ТЗ было изображение — оно прикрепляется к карточке (не только распознаётся
текстом, но и остаётся визуально видно).

## 4. Карточка задачи — кнопки

Три кнопки-эмодзи под каждой карточкой:

```
[✅]  [✏️]  [❌]
```

- **✅ Выполнено** — архивирует задачу (прячет из активного списка, не удаляет из БД — нужно для истории и статистики)
- **✏️ Изменить** — бот спрашивает «Что изменить?», пользователь отвечает свободным текстом (новый срок и/или правка сути), ИИ пересобирает карточку
- **❌ Закрыть задачу** — архивирует задачу со статусом «отменена» (та же логика хранения, что и у ✅, для точной статистики)

## 5. Меню бота (нижние кнопки)

- 🏆 **Мой отчёт** — ранг и связанная статистика (раздел 6)
- 📊 **Статистика задач** — сколько сейчас открытых задач, сколько закрыто всего, сколько закрыто в этом месяце из поступивших в этом месяце
- ➕ **Новая задача** — ручной ввод задачи (раздел 2.1)
- ⚙️ **Настройки** — смена языка интерфейса и т.п.
- ❓ **Помощь** — см. раздел 9

## 6. Геймификация: ранги

Ранг считается по количеству выполненных задач **за календарный месяц** и
обнуляется 1-го числа. Пользователь может посмотреть ранг текущего и прошлого
месяца. Раз в год, в январе, доступен годовой отчёт — сводка динамики рангов и
общего числа выполненных задач за прошедший год.

Черновая лестница из 10 уровней (пороги — ориентировочные, легко настраиваются):

| Уровень | Название | Задач за месяц |
|---|---|---|
| 1 | Стажёр | 0–4 |
| 2 | Джуниор-выживальщик | 5–14 |
| 3 | Заслуженный многозадачник | 15–29 |
| 4 | Мастер дедлайнов | 30–49 |
| 5 | Гуру таск-трекера | 50–79 |
| 6 | Повелитель ТЗ | 80–119 |
| 7 | Легенда офиса | 120–169 |
| 8 | Стальные нервы | 170–229 |
| 9 | Босс продуктивности | 230–299 |
| 10 | Терминатор задач 🤖 | 300+ |

## 7. Мультиязычность

- Интерфейс (кнопки, команды, уведомления) — на трёх языках: русский, узбекский
  (латиница), английский
- Язык выбирается при регистрации, меняется позже через «⚙️ Настройки»
- Текст самой задачи **не переводится** — остаётся на языке, на котором её написал
  автор (коллега или сам пользователь)

## 8. Изображения в ТЗ

- Если задача пришла с фото (скриншот, фото рукописного текста и т.п.) — Claude
  читает текст/контекст прямо на картинке (включая случаи без подписи вообще) и
  включает это в структурирование
- Оригинальное изображение прикрепляется к структурированной карточке
- Альбом из нескольких фото — считается одной задачей (см. 2.2)

## 9. Текст помощи / онбординга

Показывается по `/start` и по кнопке ❓ Помощь:

> Привет! Я помогу превратить любое рабочее ТЗ в понятную задачу с дедлайном.
>
> **Как пользоваться:**
> 1. Просто перешли мне сообщение с задачей от коллеги — или нажми ➕ **Новая задача**, если хочешь напечатать её сам
> 2. Я разберу текст (и фото, если есть) и через пару секунд пришлю карточку: от кого, срок, суть задачи
> 3. Исходное сообщение само удалится через 2 минуты, чтобы не захламлять чат
> 4. Под каждой карточкой — три кнопки: ✅ выполнено, ✏️ изменить, ❌ закрыть
> 5. В меню внизу — 🏆 **Мой отчёт** (твой ранг за месяц) и 📊 **Статистика задач**
>
> Сменить язык — в ⚙️ Настройки.

## 10. Технический стек

- Бэкенд: NestJS + Prisma + PostgreSQL (тот же стек, что у Terracotta Beauty и
  остальных продуктов IPAKOR)
- Хостинг: тот же общий VDS (ahost.uz, TAS-IX, Ташкент), что и остальные продукты
  IPAKOR — переезд на отдельный VDS только при значительном росте пользователей
- Telegram Bot API — форвард-сообщения, `deleteMessage` для автоудаления входящих в
  приватном чате, inline-кнопки на карточках, custom reply-keyboard для нижнего меню
- ИИ-структурирование — **Claude API, модель Haiku** (оценка себестоимости: при 30
  пользователях × 30 задач/месяц ≈ $2–7/месяц — пренебрежимо мало на этом масштабе)
- Для отчётов по месяцам/годам — отдельная таблица «итоги месяца» на пользователя
  (месяц, год, число выполненных задач, ранг на конец месяца), а не только текущее
  состояние задач

## 11. Монетизация

Подписочная модель. Оплата — **автоматически через Click/Payme с самого запуска**
(в отличие от telegram-shop-builder, где оплата принимается вручную).

## 12. Принятые решения (сводка)

| Вопрос | Решение |
|---|---|
| ИИ-платформа | Claude API, модель Haiku |
| Склейка нескольких сообщений | Пауза-таймер 3-5 сек |
| ❌ «Закрыть задачу» | Архивируется со статусом «отменена» |
| Автоудаление исходника | 2 минуты после отправки карточки |
| Автоопределение приоритета | Нет, не делаем пока |
| Оплата подписки | Автоматически через Click/Payme |
| Дедлайн не указан в тексте | Поле показывает «не указано» |
