# ТЗ-бот (IPAKOR)

Telegram-бот, который превращает пересланные рабочие сообщения в структурированные
карточки задач (от кого / дедлайн / суть) с помощью Claude API (Haiku), с
геймификацией, статистикой и мультиязычным интерфейсом (ru/uz/en).

Полное ТЗ — см. `docs/TZ.md`.

## Стек

- NestJS + Prisma + PostgreSQL
- Telegram Bot API через `telegraf` / `nestjs-telegraf` (long polling)
- Claude API (модель Haiku) для структурирования текста и чтения изображений

## Запуск локально

1. `cp .env.example .env` и заполнить:
   - `TELEGRAM_BOT_TOKEN` — токен от @BotFather
   - `DATABASE_URL` — строка подключения к PostgreSQL
   - `ANTHROPIC_API_KEY` — ключ Claude API
2. `npm install`
3. `npm run prisma:migrate` — создаст таблицы (`User`, `Task`, `MonthlyStat`, `Payment`)
4. `npm run start:dev`

### Через Docker Compose (ближе к продакшену на VDS)

1. `cp .env.example .env` и заполнить `TELEGRAM_BOT_TOKEN`, `ANTHROPIC_API_KEY`
   (`DATABASE_URL` compose подставит сам, указывать не обязательно)
2. `docker compose up -d --build`

Поднимет Postgres + бота, применит миграции (`prisma migrate deploy`) при старте
контейнера бота.

## Структура

```
src/
  telegram/      — хендлеры бота: /start, форвард/ручной ввод, карточки, меню
  ai/             — обёртка над Claude API (структурирование ТЗ)
  collector/      — склейка нескольких сообщений/альбомов в одну задачу (пауза-таймер)
  tasks/          — CRUD задач, статистика
  gamification/   — ранги, месячный cron-снепшот, годовой отчёт
  users/          — регистрация, язык, состояние диалога
  i18n/           — переводы ru/uz/en
  payments/       — заготовка подписки (Click Business, см. ниже)
  prisma/         — Prisma-клиент как Nest-сервис
```

## Что уже реализовано (MVP)

- Форвард сообщения → автосбор (текст с паузой 3-5 сек, альбомы по `media_group_id`) → Claude → карточка
- Ручной ввод через «➕ Новая задача» (`от кого` = «Себе»)
- Определение отправителя из форварда, включая случай скрытого имени (ручной ввод по запросу)
- Карточка с кнопками ✅ / ✏️ / ❌, автоудаление исходника через 2 минуты
- Меню: 🏆 Мой отчёт, 📊 Статистика задач, ➕ Новая задача, ⚙️ Настройки, ❓ Помощь
- Ранги (10 уровней), снепшот прошлого месяца по cron 1-го числа, годовой отчёт в январе
- Мультиязычный интерфейс (ru/uz-latn/en), контент задачи не переводится

## Что осталось для продакшена

- **Оплата подписки**: решили подключать **Click Business для самозанятых** — заявка
  на рассмотрении. `src/payments` содержит модель данных и сервис применения оплаты
  (`confirmPayment`/`failPayment`), но сама интеграция (вебхук/колбэк от Click, сверка
  подписи) не подключена — ждём одобрения заявки и реквизитов. Payme остался в схеме
  БД (`PaymentProvider`) на будущее, но сейчас не в приоритете.
- Деплой на общий VDS (ahost.uz) — см. `Dockerfile` и `docker-compose.yml`.
- Rate-limit / retry для Claude API на случай пиковой нагрузки.
